# Jarry's Holy Bible (Forge)

MinecraftForge port of Jarry's Holy Bible, with the same mod id (`jarrys_holy_bible`) and item id (`jarrys_holy_bible:bible`) as the Fabric and NeoForge versions.

Built for Minecraft 1.21.11 and 1.21.10 (the two releases before the 26 line). There is no MinecraftForge build for this mod on 26.x in this drop.

See `modrinth/forge-notes.txt` for the version names to use when adding these jars to the existing Modrinth project.
