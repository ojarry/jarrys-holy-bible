# Jarry's Holy Bible (NeoForge)

NeoForge port of Jarry's Holy Bible, with the same mod id (`jarrys_holy_bible`) and item id (`jarrys_holy_bible:bible`) as the Fabric version.

Built for Minecraft 26.3, 26.2, 26.1.2, 1.21.11 and 1.21.10.

See `modrinth/neoforge-notes.txt` for the version names to use when adding these jars to the existing Modrinth project.
